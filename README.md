# PDF Studio

Browser-based PDF editor. Files never leave your machine.

Features: text, freehand drawing, highlights, signatures, image placement, undo, multi-page navigation, and local save (File System Access API with download fallback).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is in `dist/`. Deploys as a static Vite site (framework: Vite, build `npm run build`, output `dist`).
